# 07: 审查中状态与切换时序

**What to build:** 审查进行时工具卡显示“自动审查中”，一次慢审查不会看起来像界面卡死。审查与用户操作交叠时结果确定：审查途中切换模式，这次审查的结果作废并按新模式处理；停止或暂停 Run 时审查被取消；切换到“自动审查”时已经在等用户的审批卡保持不变；每次调用至多审查一次。

**User stories:** 10、20、57、58、60。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 审查开始时向界面推送“自动审查中”，形状取自设计稿，不入库
- [ ] 工具卡在审查期间显示“自动审查中”，审查结束后由随后的审批条目决定显示
- [ ] 重连后不恢复这个状态，工具卡回到普通的等待显示
- [ ] 审查结果生效前按当时的模式与规则复核：新判定放行则执行，拒绝则以规则拒绝，仍需询问则直接问用户且不重审
- [ ] 审查途中切到 default：审查结果不生效，出现审批请求
- [ ] 审查途中切到 full-access：调用按模式放行执行，没有 Reviewer 的允许决定
- [ ] 审查途中新增匹配的拒绝规则：调用以规则拒绝
- [ ] 切换到 `auto-review` 时已在等待的请求保持等待，没有审查请求
- [ ] 用户回答之前的重新判定、“总是允许”保存后的重新判定不触发审查
- [ ] 停止或暂停 Run 时进行中的审查被取消，调用按现有的“停止或暂停时未批准”处理，没有允许决定的条目
- [ ] Sidecar 在审查途中退出：重启后该调用按现有的未执行调用恢复规则处理，不自动重审
- [ ] 交叠位置用 barrier 或受控 promise 确定，不用固定 sleep 或重复运行代替
- [ ] gate 的运行时级测试：每次调用至多调用一次 Reviewer 端口；取消之后到达的结果不生效
- [ ] 集成测试覆盖途中切换模式的三种结果与停止时取消
- [ ] renderer 的 Browser Mode 测试覆盖“自动审查中”的显示与结束
- [ ] 中英文文案齐全
