**What to build:** 用户可以直接打开现有 Session，查看压缩与被回退区间，按原有规则回退或分叉，并在归档或 worktree 已移除时可靠只读。新的分组结构不会要求迁移或改写旧记录。

## Acceptance criteria

- [x] 旧 Session Entry 使用当前协议直接派生新视图；运行起点或部分记录缺失时保持真实内容，不推测 Run 归属、补造时间或迁移/回填记录。
- [x] 压缩分隔、摘要及被回退区间保留，展开旧区间能检查其历史；历史内容与当前有效过程不混组，原有重试资格和操作禁止条件保持。
- [x] 回退/分叉入口、确认、目标消息和返回草稿行为符合原有契约，执行后读取持久化条目及适用文件事实核对结果，不能以 UI 消失证明回退成功。
- [x] 归档、运行中、待审批、待结果确认及 worktree 已移除的限制继续有效；只读历史可以查看工具和过程，但不能借新入口发送或执行受限动作。
- [x] 重新打开或经现有入口加载更早记录时，已存在的消息、过程组和工具身份保持稳定；新增真实边界正确重算折叠资格，没有新建分页协议。
- [x] Browser Mode 与当前可控 Sidecar/Electron 场景覆盖旧历史、嵌套回退区间、压缩、分叉和只读；用双主题与长历史证据确认显示完整，不改变原有 Checkpoint 和 SQLite 约定。
