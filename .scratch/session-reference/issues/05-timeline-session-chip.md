# 05: 时间线上的会话引用

**What to build:** 一条带会话引用的用户消息在时间线上显示 `@会话标题` 而不是一串 id；气泡下方有一个会话 chip，点击打开那次会话。附上的记录不出现在气泡正文里。被引用的会话后来改名或删除，历史消息仍显示提交时的标题。

**User stories:** 49–54。

**规格：** [spec.md](../spec.md) 的“时间线”。

**Blocked by:** 02

**Status:** ready-for-agent

开始前按 [界面约定](../../../docs/tech-stack/ui.md) 检查时间线用户消息与文件、目录 chip 的现有实现与样式。

- [ ] 用户消息的会话引用块不进入气泡正文
- [ ] 气泡正文中的 `@session:<id>` 在该消息带有对应的会话引用块时显示为 `@标题`，标题取自块；没有对应块时原样显示
- [ ] 会话引用块按出现顺序显示为气泡下方的会话 chip，与文件、目录 chip 同一行列，图标能与文件区分
- [ ] 点击会话 chip 打开该会话
- [ ] 被引用的会话不在会话列表中（已删除）时 chip 不可点击，仍显示提交时的标题
- [ ] 未附上的说明块同样显示 chip
- [ ] chip 可用键盘聚焦与激活，有无障碍名称
- [ ] 相关文案中英文齐全
- [ ] renderer 的 Browser Mode 测试：气泡显示 `@标题`、下方有会话 chip、点击切换会话、会话不在列表中时不可点击、没有对应块时原样显示、文件与会话 chip 混排的顺序
- [ ] 当前行为文档同步：上下文管理的“引用 chip”
- [ ] 记录实际运行的检查，并说明哪些交互在 Browser Mode 中验证、哪些未验证
