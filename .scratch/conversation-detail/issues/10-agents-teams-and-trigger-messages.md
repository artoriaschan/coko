# 10: 协作与触发消息适配

**What to build:** 用户在新的消息区域中继续识别子代理活动、团队消息和任务、定时触发及 Handoff，能按原有入口检查协作内容与来源，子 Session 阅读保持正常。

**Spec:** [对话详情与工作步骤复刻规格](../spec.md)

**Spec scenarios:** AC-15（子代理、团队、定时、Handoff）、AC-24、AC-25

**User stories:** 17、19、20、22、25—27、29—31

**Blocked by:** [03：详细模式与三级折叠](03-detailed-process-groups-and-folding.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 子代理工具卡及通知、团队消息与任务、定时触发和交接条目按参考风格显示，保留真实来源、名称、正文、状态与顺序。
- [ ] 已有子代理、团队、调度和交接操作使用当前身份与回调；不因展示适配新增 Agent、任务或调度，也不从文案推断完成。
- [ ] 过程开始后的可见协作或触发输入正确影响分组与整轮折叠资格；纯元数据或隐藏上下文不被错误画成用户输入。
- [ ] 父 Session、子 Session 与右栏共用时间线时都可阅读和展开，没有跨 Session 的开合串扰、重复结果或身份混淆。
- [ ] 既有审批冒泡与只读/归档等禁止条件保留，消息和任务的关键操作不因组或整轮收起不可达。
- [ ] 真实 App 覆盖运行/结束/失败的子代理、团队消息/任务、定时触发和交接；适用的 Sidecar/Electron 场景验证真实路由与结果，并保存双主题和窄窗口证据。
