# 05: 审阅卡上查看并切换执行权限

**What to build:** 用户审阅计划时能看到批准后将以哪个 Permission Mode 执行，并能在审阅卡上直接改。批准后同一个 Run 立刻继续，这是用户在执行开始前收紧或放宽权限的唯一时机。见 [规格](../spec.md) 的“阶段一：界面”。

**User stories:** 23、24

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 审阅卡标出当前的 Permission Mode，作为批准后的执行权限
- [ ] 审阅卡内放入现有的模式菜单组件，不另做一套；选择“完全访问权限”仍先确认风险
- [ ] 审阅等待期间切换 Permission Mode 后批准：后续调用按新模式判定（Sidecar 集成测试，分别覆盖收紧与放宽）
- [ ] 审阅等待期间切换模式不使计划的审批请求消失或重新判定
- [ ] 切换失败时审阅卡保留原显示并提示，审批请求仍可回答
- [ ] 右栏编辑不合格时不能批准的规则不变
- [ ] renderer 浏览器测试覆盖显示、切换与风险确认；共用 setup 对遗留模态层的断言照常通过
- [ ] 文档：Plan Mode 的界面节与桌面工作台；`pnpm run check:docs` 通过
