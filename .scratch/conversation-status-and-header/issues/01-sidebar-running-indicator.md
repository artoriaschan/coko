# 01: 侧栏“执行中”转圈（Session 行与项目行）

**What to build:** 用户在侧栏看得出哪些 Session 正在执行。Session 的 Run 正在执行时，它的行右侧显示转圈；收起的项目中有执行中的未置顶成员时，项目行显示同样的转圈。鼠标悬停或键盘焦点进入时，转圈换回原有的操作按钮；开启减少动态效果时转圈不转动。本票只用列表现有的 `running` 字段，所以当前窗口没打开过的 Session 要等列表刷新才更新；实时更新以及后台 Subagent 和 Teammate 由 02 补上。

**规格场景:** [spec](../spec.md) 的 AC-15、AC-16，以及 AC-18 中侧栏的部分；对应 RUN-02、RUN-03、RUN-04、RUN-06。

**设计依据:** 规格本身，没有单独的设计。

**文档影响:** projects 当前行为说明中“列表不显示运行状态点”改为“执行中”规则。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `running` 为真（包括 Run 内等待审批）的 Session 行，右侧对齐显示 12px 的转圈：弱化色，位置与悬停操作按钮相同，可访问名称为“运行中”。
- [ ] 鼠标悬停或键盘焦点进入行时，转圈消失，显示置顶和更多按钮；离开后转圈恢复。行菜单打开期间，操作区保持显示、转圈保持隐藏。
- [ ] 在无悬停能力、操作按钮常显的设备上不显示转圈。开启减少动态效果时图标不转动。
- [ ] 项目收起、且其中有执行中的未置顶成员时，项目行右侧显示同样的转圈，悬停或焦点进入时换成“更多项目操作”和“新建会话”。项目展开后，转圈只显示在成员行上。
- [ ] 置顶的 Session 在置顶区显示自己的转圈，不计入所属项目；置顶的项目按同样的规则处理。执行中的 Session 被分页藏起来，或整个分类被收起时，不做特殊处理。
- [ ] “执行中”不改变列表排序，也不把执行中的项上浮。
- [ ] “执行中”的判断只写在一处，02 只需在这里加入 `agentsRunning`。
- [ ] 明暗主题下，转圈不与标题或操作按钮重叠，长标题照常截断。
- [ ] 锁定旧行为的侧栏测试同步修改，原因记入 Comments。真实 App 的 Browser Mode 测试覆盖：Session 行、项目行（收起与展开）、悬停与键盘焦点下的替换、减少动态效果、置顶，以及排序不变。
- [ ] 同步修改 projects 当前行为说明。实际执行的检查（精确命令、实际数量、退出码、未验证项）和文档影响记入 Comments。
