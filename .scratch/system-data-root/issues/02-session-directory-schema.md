# 02: Session 目录字段与目录名派生

**What to build:** 数据库与协议能记录每个独立会话的实际目录与 cwd；旧版本创建的会话仍然可以打开。目录名由会话 id 确定性派生（`chat-<前 12 位>`），同一天冲突时回退为完整 id，日期按本地日期计算。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 迁移把库升级到新版本，新增会话目录与 cwd 两个字段；升级后的旧库可以正常打开，旧独立会话的两个字段为空，cwd 继续回退到 Workspace 路径。
- [ ] Session 协议 DTO 暴露 `directory`（可为空）；项目会话与子会话按现有规则返回。
- [ ] 新建或更新会话时可以写入目录与 cwd，并在读取时原样返回。
- [ ] 目录名派生是确定性的：同一会话 id 总是得到 `chat-<前 12 位>`；同一天该目录已存在时回退为完整 id；不同日期使用本地日期字符串。
- [ ] 迁移测试覆盖旧库升级、旧会话读取与字段为空时的回退；现有会话读取测试不回归。
