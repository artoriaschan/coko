# 09: 插件路径相对化

**What to build:** 已安装插件在数据库里记录相对 `COKO_HOME` 的安装路径，读取时再解析为绝对路径。用户整体移动主数据根后，已安装插件仍然可用；旧版本留下的绝对路径记录按原样继续工作。

**Blocked by:** 01 主数据根切换到 ~/.coko

**Status:** ready-for-agent

- [ ] 新安装的插件在库中存相对主根的路径，启动后能被扫描并出现在插件列表。
- [ ] 把 `COKO_HOME` 指到新位置（连同插件目录一起移动）后，插件仍能被识别与启用。
- [ ] 旧记录中的绝对路径仍可读取；路径不存在时给出与现在一致的错误，不会误删或误判为越界。
- [ ] 卸载与更新前的路径校验仍只允许主根下的路径，越界路径被拒绝。
- [ ] 集成测试覆盖相对路径解析、主根移动后的读取与旧绝对路径兼容。
