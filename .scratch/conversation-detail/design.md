# 对话过程显示契约

## 范围与依据

本设计落实 [规格](spec.md) FLOW-01—10 与 [03](issues/03-detailed-process-groups-and-folding.md)，不增加协议、数据库、迁移或执行授权。规格已确认的真实 App 接缝用于行为验证。2026-11-03 的实现细节按已授权工程判断确定；没有新的长期 ADR 或技术选型。

## 数据与身份

`buildTimeline` 继续输出扁平条目，供审批工具查找和所有既有业务消费者使用。新增的显示来源只取真实 Session Entry 的 runId、seq、createdAt；实时条目只取 live.runId。缺失归属保持独立，不从 key、文案、参数或前一个 Run 推测。工具实体仍按实际调用身份更新；相同参数不是同一个调用。

`displayRuns` 单独读取真实 run_start / run_end 的时间和状态、当前已知 live Run、未持久化结束进度，以及未回答的审批/结果确认。进度没有起止时间；缺少起点或可信终点不显示已结束耗时。运行计时只在真实连接可用时更新，断开冻结、重连追平，数字不进入状态播报。

## 分组与生命周期

非空白思考与工具仅在相邻且同一非空 Run 归属时成组。可见回复、输入、独立业务行、不同或未知 Run 截断；模型请求或工具类别不是边界。输入、所有回复、状态、业务操作和用量不进入过程折叠。未送达 Steering 仍由 Queue 唯一显示，不制造时间线边界。

每个过程组从首次运行显示起使用同一个容器。整份扁平列表只运行一次消息身份协调，live→committed 先解析成稳定身份，再按成员重叠协调组身份。新增更早成员保留重叠旧组；新增真实边界重新分组。运行生命周期独立于手动开合，回复截断的早期组在同 Run 仍运行时也保持平铺。

## 显示状态

正常 completed、有过程、过程开始后没有可见中途输入且没有未处理授权/确认限制时，整轮默认收起；无需最终答案。其他 Run 不提供整轮收起。整轮控件是独立兄弟节点，只隐藏过程座位，不包住或移动业务行。

整轮→组→单条详情依次显隐。历史组初始收起，运行和未知未结束过程保持平铺。只有显式收起整轮推进该 Run 的局部 reset epoch，清空内层开合；常规增量、工具结算或 Run 状态变化不换 key。工具与思考通过局部 Context 接收 reset，不污染业务存储。

在自动完成收起之前读取 process-seat 的焦点进入记录；焦点所在组/Run 保持展开。该例外只在运行→历史转换应用一次，之后手动组收起仍有效。手动外层收起先聚焦自己的控制按钮，再隐藏子树。门户弹窗通过 `useProcessFocusLock(active)` 注册所属过程的交互锁，默认在过程外不做事；锁覆盖完成转换后保持该组与整轮展开，关闭弹窗释放锁不会立即隐藏返回焦点目标，直到手动折叠。

## 布局与验证

过程行距 4px，回复周围 12px，整轮控件与输入/后续过程 16px；历史展开组头含 8px 底部间距，正文 cap 为 min(400px,50vh)，按真实滚动方向显示 24px mask。手动展开历史从顶部且不自动跟随；组内阅读位置与外层独立。完整长内容/历史锚点协调由后续阅读票负责，本票保留短内容基本跟随与焦点能力。

主要验证为真实 App 协议夹具；纯投影测试补充未知归属与历史揭示边界。右栏 Agents 和 Team 子 Session 使用相同投影与 Session key。视觉对照使用锁定参考提交 8bd073392eef6f54e921a093b95076248eb08cbb 的原版 ChatGroupSeat/样式，真实 Coko App 与参考外部夹具均以静默 agent-browser 操作。
