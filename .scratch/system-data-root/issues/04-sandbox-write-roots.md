# 04: Sandbox 写根收紧到 work 与 outputs

**What to build:** 独立会话的权限模型从“整个会话根可写”收紧为：权限根仍是会话根，但写根只有 `work/` 与 `outputs/`。Agent 在 `work/` 与 `outputs/` 内写文件不需要额外审批；在会话根其他位置写文件按越界写入处理并走审批。项目会话保持现有行为。

**Blocked by:** 03 独立会话目录与 work/outputs

**Status:** ready-for-agent

- [ ] 在 `work/` 与 `outputs/` 内创建、修改、删除文件按当前权限模式正常放行。
- [ ] 在会话根其他位置写文件被判定为越界，按现有审批流程处理；只读模式下同样被拒绝。
- [ ] 读取边界保持为会话根，Agent 能读取 `work/`、`outputs/` 与会话根内的其他只读内容。
- [ ] 项目会话的写根仍是项目根，不出现 `work/`、`outputs/` 的特殊规则。
- [ ] 文件 checkpoint 与文件工具在新写根下正常工作；集成测试覆盖允许、拒绝与审批三条路径。
- [ ] 写根扩展的决定同步到权限与沙箱的 ADR 或设计说明。
