# 会话数据诊断

设置 → 常规的“开发者”卡片提供默认关闭的“会话数据诊断”开关。开启后，当前 Session 右栏的“开始”页出现入口，不自动打开；关闭时，已采用布局中的诊断页被移除，未采用的布局在恢复时过滤。设置保存、失败与布局规则见[工作台](workbench.md)。

## 原始数据

页面只读当前主区 Session 在 chat store 中已经收到的 Session Entry；不读取数据库、不新增请求、不提供导出，也不加载更早数据。归档或 worktree 移除后只读的 Session 仍可查看。用户文本、登记 Secret 的替换标记与主时间线共用来源，诊断模块不再次脱敏。

每条真实条目以 seq 为身份，跳过的 seq 不补造。`run_start` 为组头，同一 Run 的其余条目按 seq 成为子行，整个组位于组头的位置；没有组头的 Run 条目和不属于 Run 的条目按 seq 作为根行。Run 列按加载条目中 Run 首次出现的顺序从 1 编号，非 Run 条目为空。

列为序号、类型、Run、UTC 毫秒时间与摘要；message 类型附角色。摘要省略已有独立列的顶层元数据，保留嵌套业务值，最多 240 字符。每行与表头固定为 30px，表格使用 Tanstack 虚拟化，保留当前吸顶祖先；序号值与表头可悬停或聚焦查看全文。超出面板宽度的列只在表格中横向滚动，工具栏可换行。

## 对话分组

“对话分组”订阅当前主时间线在提交后发布的时间线项、显示身份、过程席位和 Run，直接读取已计算出的值；诊断页不再次调用时间线或过程分组算法。只有主区的 TimelineView 显式发布，右栏的子 Session 与回退历史的嵌套时间线不覆盖它；主区卸载时只释放该挂载拥有的投影。

过程组是组行，成员紧随其后；其余独立显示项是根行。排队中的追加指令、Job 起止事实、被替代后不渲染的 Plan、空思考和被助手底栏替代的 Run 用量席位不另造行。Plan 边界仍留在原过程计算中，保持已挂载工具的身份和阅读位置。序号取实际显示身份，Run 列沿用已加载 Run 的顺序，不显示时间列。

详情保留原始对象，根节点默认展开，嵌套字段按需展开，集合每批 50 项；数组空槽、显式 undefined、符号键、Map 的真实键和 Set 的值分别保留。访问器只显示标记，不执行 getter；循环祖先显示 `$` 路径，相同对象在兄弟位置仍可独立展开。枚举失败仅在该分支提示，其他字段可继续查看；展开后的枚举在下一次投影发布前复用，发布后能看到原地更新。

Run、过程组、时间线项与来源 Session Entry 可以沿引用查看；工具同时保留 assistant 调用和实际 toolResult 的来源 seq。每次引用增加一级面包屑，返回前级截断后面的路径，第一级始终是最初选中的行。点击表格行会重新开始路径。引用对应表格行时，交给共用表格展开祖先、定位并闪烁；筛选排除目标时先清除筛选。每次引用同时请求定位主时间线；引用没有独立表格行时仍可查看当前对象并定位相应 Run 或来源。

投影发布后，同身份的行保留选择与折叠。变化比较不序列化对象，不把新分配的过程席位本身当作变化；新增或更新的行使用约 700ms 背景淡出，每行保留自己的更新代次和到期时间；同一行再次更新只重启该行，其他行完成各自的淡出。虚拟化后重新出现的行只播放剩余时段，已经到期的不重播；行 DOM、选择、焦点和滚动位置不因重启而替换。系统要求减少动态效果时不播放。

## 定位与瞄准

选中原始条目、实时进度或对话分组行，或者沿对象引用与面包屑导航时，使用主时间线的展示身份、过程组 id、Run id、来源 seq 与 toolCallId 定位。工具结果沿真实调用 id 找回工具卡；实时助手块直接采用已发布的内容块显示身份。匹配不比较文本，不切换页面或 Session。

定位请求由当前主时间线拥有，通过原有的 Run、过程组、工具与思考展开状态打开折叠层，保留手动整轮收起的 reset epoch。主区同一 Session 的回退历史继承该所有者，定位时也打开路径上的原生 details；右栏子 Session 不注册为主区。已提交布局稳定后，先调整必要的组内滚动，再调整主消息列；目标已经可见时不移动。阅读策略在展开与定位期间交出旧的贴底／锚定意图，完成后保留新的阅读位置，不将下一次尺寸变化拉回旧位置。

精确目标不可呈现时，先选择同 Run 中按来源 seq 最近的已加载内容，再尝试其他已加载内容；都没有时只提示当前可见消息列，不移动它。body 层的高亮按视口、主消息滚动区和嵌套限高组裁剪，持续约 700ms，不插入时间线节点。系统要求减少动态效果时立即滚动且不闪烁。布局等待只观察目标及其折叠路径，不被其他 Run 的实时更新或过程动画拖住。

工具栏的“瞄准”按钮开启单实例透明蒙层。悬停时预览当前元素，离开消息区清除预览；点击按现有身份属性反查当前展示形式的记录。命中后清除排除该记录的筛选、展开表格祖先、选中并打开详情；对话分组从新记录开始面包屑。未命中时显示“当前表格没有匹配记录，请选择其他元素或按 Esc 取消。”并继续等待。键盘激活后，焦点留在瞄准按钮，用上下方向键循环预览当前可见且可匹配的身份，Home/End 到首尾，Enter/空格选取。预览使用同一身份索引和裁剪区域，当前目标及操作说明通过本地化状态区和按钮描述提供。输入框、组合输入、前台弹层及带修饰键的快捷键保持原处理。

蒙层拦截 pointer、mouse、click、auxclick、双击和右键动作，底下的时间线控件不会激活。滚轮先交给指针下可滚动的嵌套区域，剩余位移再交给外层消息区。Esc、再次点击瞄准、切换展示形式或 Session、隐藏或关闭诊断页、窗口失焦都会取消；全屏或其他覆盖层使主时间线不可见时也不会拾取。取消和卸载清理监听器、动画帧与覆盖层。

## 实时增量

只在主区当前 Session 的诊断 tab 存在期间订阅 chat store 已有的 `onProgress`；隐藏右栏、切换到同一 Session 的其他 tab 或切换展示形式仍继续收集。切换 Session、关闭诊断 tab、关闭开发者开关或重新加载会清空这些内存子行。打开之前已经发出的进度不回放；不读取聊天的实时正文状态来补造旧增量，也不新增网络请求。后台任务、子代理、定时任务、团队与代码智能等脱离 Run 的进度不进入诊断。

未结算进度位于对应 Run 末尾的“实时进度”下。助手按内容块 `contentIndex` 分组，工具按 `toolCallId` 分组；生成中的组默认展开。思考与工具参数块折叠后显示最多 240 字符的拼接片段。`offset` 是 UTF-16 位置：重复或一致重叠片段不重复拼接，缺前缀、空缺或冲突时不生成误导性的拼接预览，原始帧仍能逐条检查。所有增量行的 UTC 时间列为空。

每条助手消息提交时，其前一条助手消息以来的块转到该条目下；工具进度按调用 id 转到工具结果下；压缩与 Run 起止进度归入对应条目。提交后的增量默认收起，但 Run 组头自身保持展开（起始进度使用独立收起的子组）。重试、上下文用量与未匹配的帧继续保留在实时进度下。事件顺序并非统一的先进度后条目：`run_end`、`compaction_end` 可以在条目之后到达，所以既处理新条目转交，也让迟到的结束进度匹配已经提交的条目。

## 跟随与详情

默认跟随尾部；上滚或手动折叠暂停跟随。手动折叠前测量组头位置，折叠后保持其可见位置，把所需留白放到所有数据之后。自动收束后的新行先消耗尾部留白；“跟踪最新”清除留白并恢复跟随。没有“加载更早”按钮。

选中条目后，下方 JSON 详情默认占可用高度的 40%；上缘分隔条支持拖动、上下方向键及 Home/End，限制 15%～80%，换记录时保留高度。JSON 容器默认全部展开，可以逐层折叠；同一记录收到增量时保留手动折叠，切换记录时以新记录重新展开，详情高度仍保留。循环祖先为 `[Circular]`，共享的非循环对象分别展开，大整数显示为带 n 后缀的字符串。序列化失败只在详情内显示说明，表格和其他记录仍可使用；已不存在的选择显示移除或结算提示。

## 类型筛选

类型表头的筛选按钮悬停或聚焦时显示共享 Tooltip，激活后打开共享浮层；浮层跟随按钮定位，定位完成后才聚焦输入框。候选异步读取全部已加载的行，包含被折叠或当前筛选隐藏的类型；新数据到达后更新候选，过期的查询结果不会替换当前草稿的候选。

输入只改变草稿。Enter 确认片段，方向键循环选择候选后 Enter 或直接点击候选则确认完整类型；“确认筛选”始终确认片段。输入法组合期间的 Enter 不提交。Esc、“取消筛选”、外部点击或窗口失焦放弃草稿，重新打开时恢复已确认的片段；“清空草稿”后确认恢复全部类型。

匹配不区分大小写，使用包含匹配；首尾空白与可选的 `*` 不影响匹配，空白或只有边界星号表示不过滤。筛选保留匹配行和它们的祖先；仅作为上下文的祖先使用次级字色，强制展开且不能手动收起。计数为“匹配数 / 总数”，上下文不计入匹配数；新行沿用当前已确认的筛选。每次确认清除选中、手动折叠与尾部留白，暂停跟随并回到顶部。

共享表格的引用定位请求只在目标被筛选排除时清除筛选，再展开祖先、滚动并短暂高亮；上下文中已有的目标保留筛选。定位请求不改变原先的详情选择，减少动态效果时不播放高亮动画。
