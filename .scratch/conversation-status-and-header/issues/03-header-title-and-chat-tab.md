# 03: 标题栏改为标题行与“对话”tab 行，移除连接状态与费用

**What to build:** 对话详情页的标题栏分两行。上面是标题行：标题、worktree 分支 chip，以及后台任务、子代理、定时任务、团队四个状态按钮。下面是 tab 行，只有一个选中的“对话”tab，采用下划线式。Sidecar 连接指示和 Session 费用按钮从标题栏移除：连接变化仍由只给读屏器的状态元素播报，启动失败时的全屏提示保留；Session 费用仍可在 Trace tab 和 Goal 卡中查看。

**规格场景:** [spec](../spec.md) 的 AC-07 中标题行与 tab 行的部分（“更多”和“打开侧边栏”分别由 05、06 交付，完整组合由 09 验证），以及 AC-08；对应 HEAD-01 至 HEAD-04。

**设计依据:** 规格本身，没有单独的设计。

**文档影响:** workbench 当前行为说明的标题栏部分；goal 中删除标题栏费用的契约。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 标题行保持 48px 高。标题为 14px、字重 500，单行截断，并能读到完整标题；分支 chip 紧跟在标题后面。四个状态按钮的行为不变。新对话页不显示标题和 tab 行。
- [ ] tab 行只有一个选中的“对话”tab：下划线式，13px、字重 500，选中时文字与 2px 下划线均为 link 蓝，tab 行下方有一条细分隔线。保留 tab 列表与 tab 的语义；点击不切换内容。交互控件按共享规则退出窗口拖拽区。
- [ ] Sidecar 连接指示（圆点与文字）不再出现在标题栏。连接变化仍由视觉隐藏的状态元素播报。先查清现有 E2E 依赖的就绪信号，保证它们继续可用：例如 first-send E2E 在新对话页上也会等待连接就绪，而新对话页的标题栏不渲染连接状态。启动失败时的全屏提示层照常出现。
- [ ] Session 费用按钮及其悬停分项卡不再出现在标题栏。格式化、定价与货币函数保留；Trace、Goal 和 Subagent 中的费用展示不受影响。
- [ ] 标题与 tab 的样式使用 Coko 现有的语义 token，不新增全局 token。文案走 zh/en 类型化字典。
- [ ] 断言旧行为的测试同步修改，原因记入 Comments，例如断言费用按钮或可见连接文字的测试。真实 App 的 Browser Mode 测试覆盖：两行结构、tab 语义、两项移除，以及读屏状态元素。
- [ ] 同步修改 workbench 与 goal 当前行为说明。实际执行的检查和文档影响记入 Comments。
