# 07: 评测：预置记忆与两个用例

**What to build:** 分层与检索是否有效可以被衡量。评测运行器增加两项能力：在 Run 开始前经记忆接口预置一组条目；faux 脚本能引用预置条目的 id（预置后由运行器把占位符替换为实际 id）。在此之上新增两个 Eval Case：“摘要层中的记忆被读出”——预置的条目使答案所在的条目落在摘要层，模型按 id 读取后把答案写入文件；“靠检索找到记忆”——预置的条目使答案所在的条目落在检索层，模型用与正文措辞不同的 `query` 找到它并写入文件。faux 模式下两个用例通过；真实模式在没有 Provider 配置或凭据时记为 `skipped: no-credentials`，不阻塞交付。

**规格场景:** [spec](../spec.md) 的 AC-31、AC-32；Testing Decisions 中的“评测”；Further Notes 中的“真实模型未验证”；用户故事 27。

**文档影响:** [追踪、审计、导出与评测](../../../docs/subsystems/tracing.md#评测)的用例格式表增加预置记忆的字段与占位符说明、当前用例列表增加两个用例；[测试约定](../../../docs/tech-stack/testing.md)中列举评测判定依据处同步。

**Blocked by:** 03 摘要层；05 检索的近似匹配

**Status:** ready-for-agent

- [ ] Eval Case 支持在 Run 开始前预置一组记忆条目（正文与作用域）；预置只经记忆接口，不写库文件；加载用例时校验格式，格式错误给出一条原因。
- [ ] faux 脚本中可以用占位符引用预置条目的 id，运行器在预置后替换；引用不存在的预置条目在加载或运行前报错，不静默通过。
- [ ] 预置字段与占位符替换由单元测试覆盖，包括格式错误与引用越界。
- [ ] AC-31：“摘要层中的记忆被读出”在 faux 模式下通过：预置的条目数量与长度使答案所在的条目落在摘要层，期望以文件内容判定。
- [ ] AC-32：“靠检索找到记忆”在 faux 模式下通过：答案所在的条目落在检索层，faux 脚本的 `query` 与条目正文措辞不同，靠近似匹配命中。
- [ ] 两个用例不依赖项目归属与任何允许规则；没有 `COKO_EVAL_PROVIDER_CONFIG` 或对应凭据时，报告中真实模式为 `skipped: no-credentials`。
- [ ] 反向验证：把答案条目移出预置或把期望改成不匹配的内容时用例失败并给出原因，之后改回。
- [ ] 具备凭据时运行真实模式并把结果单独报告；不具备时在 Comments 中明确记为未验证，不把 faux 通过表述为模型会主动读取摘要或检索。
- [ ] 按[测试约定](../../../docs/tech-stack/testing.md#测试执行与结果报告)运行最小相关集与类型检查；实际执行的检查和文档影响记入 Comments。
