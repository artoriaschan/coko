# 07: 输入框底部状态栏与 Token 用量

**What to build:** 对话详情页的输入框卡片下方出现状态栏，水平居中，与输入框共用列宽；输入框卡片底边到主区底边的距离从 16px 增加到 30px。状态栏先显示 Token 胶囊，内容是整个 Session 的用量（不含 Subagent 的子 Session），格式为 `45.2K tok · 缓存命中 90%`。点击胶囊打开 Token 卡，显示精确总量和各分项，不显示费用。Session 已归档、worktree 已移除的只读状态下，以及审批卡或结果确认卡占用输入位置时，状态栏照常显示。没有数据时输入框不跳动。

**规格场景:** [spec](../spec.md) 的 AC-01 中 Token 与布局的部分、AC-03、AC-04、AC-05 中单张卡的部分、AC-06；对应 STAT-01、STAT-02、STAT-03、STAT-06 至 STAT-10。

**设计依据:** 规格本身，没有单独的设计。

**文档影响:** workbench 当前行为说明的输入区与状态栏。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 状态栏只在详情页出现，新对话页不显示。在 Session 详情页的整个生命周期内保持挂载：输入框、审批卡、结果确认卡与归档/只读提示之间切换时，不重新挂载。
- [ ] 尺寸：输入框卡片底边到状态栏 4px，状态栏高 22px，状态栏到主区底边 4px，合计 30px。胶囊为 12px 弱化色文字，胶囊之间间距 12px；图标 14px、stroke 1。空间不够时用省略号截断，不换行。没有数据时保留 22px 空行。
- [ ] Token 总量复用现有的 Session 级汇总：包括主循环、压缩、交接摘要与标题生成请求，不包括 Subagent 的子 Session；只累计服务商已上报的分桶。胶囊显示 `45.2K tok · 缓存命中 90%`，图标为数据库。没有输入时省略缓存命中部分；没有任何用量计数时不显示胶囊。
- [ ] Token 卡的标题行：左侧为数据库图标加“Token 用量”，右侧为带千位分隔的精确总量。之后依次为缓存命中、未缓存输入、缓存读取、缓存写入、输出，以及推理（确有数据时才显示）。只在有未上报的分项时显示“数据不完整”说明。不显示费用。
- [ ] 把“本轮用量”卡的字段渲染抽成两张卡共用的部分；“本轮用量”卡的外观与行为不变。
- [ ] 点击胶囊打开或关闭卡片；点击外部或按 Escape 关闭，焦点回到胶囊。同一时间只开一张卡。卡片默认出现在上方，靠近视口边缘时自动调整位置，不被裁剪。胶囊的可访问名称包含完整读数，只在文字被截断时显示 Tooltip。
- [ ] 数值随条目提交更新，流式输出过程中不变化；重新加载与重启后与持久化事实一致，不重复计数。上下文环留在输入框工具栏的原位。
- [ ] 状态栏的行结构要允许 08 把会话统计胶囊加在 Token 胶囊之前。
- [ ] 断言输入区底部间距的测试同步修改，原因记入 Comments。真实 App 的 Browser Mode 测试覆盖：读数、卡片、交互、视口边缘，以及归档/只读/卡片占用三种状态。代表性的 E2E 检查 faux Run 之后的读数。
- [ ] 同步修改 workbench 当前行为说明。实际执行的检查和文档影响记入 Comments。
