# 06: 回退、分叉与交接中的计划阶段

**What to build:** 计划阶段跟着对话内容走。回退到进入规划之前，Session 不在规划中；回退到批准之前，Session 回到规划中，写入再次被拒。从规划中的 Session 分叉或交接出的新 Session 也在规划中。Permission Mode 现有的回退行为不改。见 [规格](../spec.md) 的“阶段一：协议与入口”中的分叉、交接与回退两条。

**User stories:** 35、36、37

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 计划阶段与 `plan` 条目的状态按有效条目回放；回退后服务端重新计算，不沿用回退前的结果
- [ ] 回退到进入规划之前的消息：计划接口读回“无”，下一个 Run 没有 `<plan_mode>` 与提交工具，写入按 Permission Mode 判定
- [ ] 回退到批准之前的消息：读回“规划中”，写入被拒，提交工具可用，被回退掉的已批准记录不再算作当前计划
- [ ] 桌面的计划阶段派生与服务端同口径：回退后 Plan chip 与计划卡的显示和协议读回一致
- [ ] 分叉：两种边界下，边界处在规划中的新 Session 以规划中开始，不在规划中的不带；`plan` 条目不复制
- [ ] 交接：源在规划中时目标 Session 在规划中
- [ ] Permission Mode 的回退行为保持现状，用例中明确断言这一点
- [ ] Sidecar 集成测试覆盖以上各项，沿用现有的回退、分叉与交接测试
- [ ] 文档：Plan Mode 的状态节，以及回退、分叉与交接所属文档中的计划阶段说明；`pnpm run check:docs` 通过
