# 03: 用户消息底栏

**What to build:** 用户气泡底部显示真实发送时间、复制 icon 和“回退到此处”icon，不再提供“从这里分叉”；用户能通过指针或键盘完成操作，既有回退确认和文件恢复语义保持有效。

**Spec:** [消息底栏与本轮用量规格](../spec.md)

**Spec scenarios:** AC-03、AC-08（用户时间）、AC-09（用户显隐）、AC-10、AC-21（用户底栏）

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Closed:** true

## Acceptance criteria

- [x] 用户气泡底部依次显示发送时间、复制、回退，不显示分叉或本轮用量；使用现有图标、共享控件、Coko 视觉 token 与 zh/en 字典。
- [x] 时间始终可见，来自消息实际提交记录；默认本地时区 24 小时 HH:mm，悬停和键盘路径能读到完整日期及秒。重载不改变时间含义，缺少可信时间的旧记录不补造时间。
- [x] 复制得到用户发送的原始文本，不混入时间、操作标签或展开的模型上下文；成功时图标短暂变勾并提示“已复制”，失败使用现有错误反馈且不假报成功。
- [x] 有 hover 能力时复制和回退在悬停或键盘焦点进入后显示；时间始终显示。无 hover 能力时操作可见，按钮有可访问名称和 Tooltip，焦点清晰且不会因显隐丢失。
- [x] 回退打开既有三模式确认框，默认“对话和代码”；取消不改变任何上下文或文件，执行对话回退时沿用目标文本返回输入区和已有草稿合并规则。
- [x] 文件预览、偏离提示、文件工具追踪范围、bash/外部副作用说明及禁止条件仍有效；被回退内容按既有追加记录语义保留，不删除原始记录或绕过授权。
- [x] 通过实际 App 装配验证显示、复制、回退、取消和限制；通过既有 Sidecar/Electron 相关入口确认回退后的上下文与文件事实，更新原用户分叉入口的旧测试预期。
- [x] 验证明暗主题、zh/en、390 CSS px 及以上主内容宽度、长内容和键盘路径，不产生整页横向滚动、不破坏选区和阅读位置；同步所属当前行为文档。
