# 05: 文件读取与修改详情

**What to build:** 用户展开读取、写入和编辑调用，能通过参考项目对应的读取视图、文件内容或 diff 核对实际操作，并使用现有的行号、统计、复制和文件入口。

**Spec:** [对话详情与工作步骤复刻规格](../spec.md)

**Spec scenarios:** AC-10（文件）、AC-11（缺失专用字段）、AC-12（文件工具）、AC-24

**User stories:** 11、13、16、18、27、29—31

**Blocked by:** [02：工具摘要行与通用详情](02-tool-rows-and-generic-details.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 分别对照读取、写入和编辑的参考专用视图，复刻正文容器、工具栏、行号、文件标识、增删展示、统计及错误信息，不用通用文本外框冒充已支持的专用详情。
- [ ] 从 Coko 当前参数和真实结果提取路径、内容与可获得的 diff；缺少旧内容、完整文件或变更信息时不重建虚假 diff，不更改后端协议或回填历史。
- [ ] 多段修改、空文件、长路径、长代码行、工具失败以及缺失专用字段均保留可检查的真实信息；现有截断信息和可查看剩余内容的入口不丢失。
- [ ] 文件与代码内容保持原文，局部横向滚动；复制和已有文件打开能力按真实内容与宿主边界工作，不能因展开详情再次修改文件。
- [ ] 实时到提交保持调用和展开身份稳定；未执行、拒绝或 Hook 阻断不得显示为成功修改。
- [ ] 真实 App 验证读、写、编辑及缺失数据/错误路径；通过现有可控执行入口读取实际文件与记录验证内容一致，保留双主题和窄窗口的专用视图对照。

## 范围与衔接

仅依赖 02；文件专用正文内部的可复用展示能力由本票负责。持久化、Checkpoint 与 Rewind 规则不在本票改动范围。

规格锁定的参考提交、Coko 数据边界与非目标持续适用。不得修改数据库、协议和既有执行授权来凑齐展示数据，也不得用全局样式变化影响范围外页面。每票按实际变更更新所属当前行为文档；长期文档不反向链接本票。

## 验证与回执

- 采用规格的真实 App 装配入口及本票要求的现有 Sidecar/Electron 入口；纯函数测试只补充边界，不代替用户可见路径。
- 按当前实际改动选择相关测试，运行类型和文档检查；保留精确命令、实际数量、退出码、参考/当前对象版本、主题/语言/尺寸及可访问证据。只更新失效证据，不用盲目重试、固定 sleep 或放宽断言制造通过。
- 视觉与交互默认静默 agent-browser/CDP。获取资源后登记清理，结束时等待所属会话和进程实际退出，保留无关运行实例与用户数据。
- 完成后在 Comments 追加实施、验证、文档影响和实际交付状态；仍有必要验收缺口时如实记录，不提前关闭。不因前置票以 wontfix 关闭就自动认定阻塞解除。
