## Acceptance criteria

- [x] 对现有搜索与有对应物的结构化结果，逐项对照参考标题、摘要、分区、列表、字段、工具栏和错误/空结果样式；未知结果继续完整使用 02 的通用详情。
- [x] 搜索位置、路径、行号、结果数量与截断提示只来自可证明的当前数据；保留完整可查看内容，不从结果文字随意猜造结构或成功计数。
- [x] LSP 和 Memory 等既有工具保留原操作语义、可检查参数/结果及已有位置入口；没有参考对应物时使用同套视觉规则，不增加新的工具能力。
- [x] 搜索结果中的代码与用户内容保持原文；长路径、长匹配行、空集合、失败及字段缺失在正常宽度和 390 CSS px 下均可查看。
- [x] 详情里的链接、文件或追踪操作遵循现有回调与键盘规则，不误触整行折叠、不出现死入口。
- [x] 真实 App 覆盖有结果/无结果/失败、长内容、现有 LSP/Memory 结果与通用结果；提交对应双主题视觉及交互证据。
