# 04: 命令终端详情

**What to build:** 用户展开命令调用后看到与参考一致的终端详情，可以检查真实命令、实时输出、已有退出状态并使用对应工具栏；后台运行的命令仍能进入 Coko 已有 Background Job。

**Spec:** [对话详情与工作步骤复刻规格](../spec.md)

**Spec scenarios:** AC-10（命令）、AC-12（终端增量）、AC-15（后台任务关联）、AC-24

**User stories:** 11、12、16、18、19、27、29—31

**Blocked by:** [02：工具摘要行与通用详情](02-tool-rows-and-generic-details.md)

**Status:** ready-for-agent

**Closed:** true

## Acceptance criteria

- [x] 完整对照参考终端正文、命令与输出排版、现有工具栏、复制反馈、退出状态及错误表现，接入 Coko 实际命令参数、进度和结果。
- [x] 流式输出、普通结束、非零退出、停止和无结果场景正确区分；无数据的退出码或耗时不显示为推测值，审批/Hook 阻断不伪装成已运行命令。
- [x] 输出保留原文及当前支持的 ANSI 信息；长行在终端内部横向滚动，长输出完整可检查，不能通过整页溢出或无提示裁剪解决。
- [x] 展开状态与终端内部阅读位置在 partialResult、已提交结果及状态更新之间稳定；重复结果不生成第二个调用。
- [x] 后台 Job 关联继续使用已有身份与入口；从命令详情进入任务视图可查看真实任务，不新造执行或轮询机制。
- [x] 真实 App 验证命令输入、连续输出、退出/错误、复制及后台任务入口，双主题和 390 CSS px 下核对专用详情与参考；涉及宿主操作时补对应真实入口证据。
