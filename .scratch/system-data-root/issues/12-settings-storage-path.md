# 12: 设置存储路径

**What to build:** 设置界面增加只读的存储区域，显示主数据根 `~/.coko`（或 `COKO_HOME` 指向的实际路径）与独立会话根 `<Documents>/Coko` 的实际路径，并提供“打开目录”按钮。路径不能在这里修改。

**Blocked by:** 01 主数据根切换到 ~/.coko；10 新建空白项目

**Status:** ready-for-agent

- [ ] 设置界面能看到主数据根与独立会话根的实际绝对路径，`COKO_HOME` 覆盖时显示覆盖后的路径。
- [ ] “打开目录”按钮能打开对应目录；目录不存在时给出明确提示而不崩溃。
- [ ] 界面不提供修改路径的输入框；说明路径由环境变量控制。
- [ ] 浏览器测试覆盖路径展示与打开按钮调用；桌面 e2e 覆盖设置分区的实际文本。
