# 04: 助手底栏与用量详情卡

**What to build:** 成功结束的每个 Run 在最终助手正文下显示一个底栏，用户可复制正文、查看本轮 token 明细及结束时间；移除该场景的旧独立用量行，新底栏与详情卡不展示费用。

**Spec:** [消息底栏与本轮用量规格](../spec.md)

**Spec scenarios:** AC-01、AC-02、AC-08（助手时间）、AC-09（助手显隐）、AC-13（明细）、AC-14（真实零展示）、AC-16、AC-17、AC-20、AC-21（助手底栏与卡片）

**Blocked by:** 01 — 正常请求的真实用量

**Status:** ready-for-agent

**Closed:** false

## Acceptance criteria

- [ ] 正常成功结束且有最终回复时，每个 Run 只在最终助手正文下出现一个底栏；阶段回复不挂重复底栏，生成中不提前显示结束底栏，旧独立用量行在本场景移除。
- [ ] 底栏提供复制、本轮 token 入口及结束时间，并能由 05 接入位于复制与用量之间的分支动作；本票不放置无回调的分支死按钮，也不等待 05 才能演示其余功能。
- [ ] 复制该条助手回复原始 Markdown，不含思考、工具、用量或时间；成功显示短暂勾号和“已复制”，失败沿用应用级反馈且不显示成功。
- [ ] 结束时间来自 Run 结束记录并始终可见，使用本地 24 小时 HH:mm，悬停或键盘查看完整日期及秒；不误用最终助手消息开始/完成时间或重新查看时间代替 Run 结束。
- [ ] 最新回复的操作和用量常显，历史回复在悬停或聚焦时显示，无 hover 能力时保持操作可见；时间不隐藏。显隐与浮层开关不丢失焦点、正文选区或阅读位置。
- [ ] token 紧凑显示，点击打开详情；卡内展示可信精确计数、Provider/模型归属、缓存命中率、四个互斥分桶及确有数据的 reasoning 子集。多个模型或部分字段不能误表述为单模型或完整精确统计，真实零与不完整状态使用 01 的事实。
- [ ] 新底栏及卡片不展示费用；现有会话累计费用、预算、定价和审计能力继续有效，不因移除费用文案删除底层计量。
- [ ] 卡片可再点触发器、外点和 Escape 关闭，焦点按共享组件规则返回；优先在上方展示并处理视口边缘和长内容，不被消息容器裁剪，不因父行失去 hover 而消失。
- [ ] 通过实际 App 装配验证上述输出与交互；覆盖明暗主题、zh/en、390 CSS px、长模型名、键盘和可选字段缺失，更新可见输出预期及所属当前行为文档。

## 范围与衔接

依赖 01 的稳定计量事实与兼容读取，不依赖 02 是否已扩展到全部异常请求；02 完成后同一详情自然反映其聚合结果。本票不私自实现第二套统计来源。05 接入助手分支，06 补齐停止、失败和无最终正文的结束布局；本票保留这些场景的既有关键状态和数据，不提前制造信息缺口。
