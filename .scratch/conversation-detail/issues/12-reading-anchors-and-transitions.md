# 12: 阅读位置与折叠过渡

**What to build:** 用户可以连续阅读流式输出、长过程组和更早历史；向上阅读后不会被强拉到底部。整轮折叠、工具高度变化与焦点切换按参考协调为连续过渡。

**Spec:** [对话详情与工作步骤复刻规格](../spec.md)

**Spec scenarios:** AC-12（尺寸变化后的阅读）、AC-19、AC-20、AC-21（锚点）、AC-23、AC-24

**User stories:** 5、6、16、24—30

**Blocked by:** [03：详细模式与三级折叠](03-detailed-process-groups-and-folding.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 外层消息区在贴底时跟随，向上阅读时暂停，回到底部或主动返回底部时恢复；工具结算、Run 完成和其他内容增高不抢占阅读位置。
- [ ] 限高组内部与外层的跟随状态独立，边缘滚动可继续传给外层；展开历史组从顶部开始，组关闭或恢复限高不重置已有阅读位置。
- [ ] 在现有历史加载入口锚定实际可见内容，追加更早内容后保持其位置；请求期间用户滚动优先，隐藏项与整轮控制项不会成为错误锚点。
- [ ] 整轮折叠、平铺转历史组、工具正文变化与新增内容协调，过渡结束不再额外跳一次，不为屏外步骤保留无依据底部空白。
- [ ] 流式更新、结算和普通显隐变化不丢选区、开合与焦点；按基线显式收起整轮时允许的内部开合重置与普通更新区分。
- [ ] 自动收起不能隐藏键盘焦点，手动收起恢复至控制项；阅读手势可中断自动跟随，reduced-motion 下保留正确位置与可访问反馈。
- [ ] 真实 App 使用可控长内容、尺寸变化和真实滚动行为验证以上结果，断言可见锚点/几何与焦点；静默 CDP 记录动画及交互证据，不用固定等待时间冒充完成。
- [ ] 在双主题、正常/390 CSS px 主内容宽度及相关子 Session 消费者验证；为 13 与全部专用工具的联合场景保留可复用验证入口。

## 范围与衔接

只依赖 03，先通过通用详情的真实动态尺寸验证阅读算法；04—07 不构成算法实现的前置阻塞，13 必须联合验证各专用详情。不能以测试用 class 名或 CSS 常量代替实际位置与滚动结果。
