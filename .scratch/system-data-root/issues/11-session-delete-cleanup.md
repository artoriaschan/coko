# 11: 删除清理与归档

**What to build:** 删除独立会话时，只有当会话目录除 `work/`、`outputs/` 外没有其他内容，且这两个目录都为空，才删除目录，并删除没有其他会话引用的 Workspace 记录；否则保留目录，并在删除确认中显示保留路径。删除同时清理该会话的附件与工具结果目录，保留 MCP 数据。归档会话不删除任何文件。

**Blocked by:** 03 独立会话目录与 work/outputs；06 附件副本；07 超长工具结果落盘

**Status:** ready-for-agent

- [ ] 删除一个只有空 `work/`、`outputs/` 的独立会话后，会话目录被删除，Workspace 记录被清理。
- [ ] 删除一个有内容的会话后，目录与 Workspace 记录保留，确认框显示保留路径并允许复制。
- [ ] 删除会话时 `data/attachments/<sessionId>/` 与 `data/tool-results/<sessionId>/` 被清理；`data/mcp/` 不受影响。
- [ ] 归档会话不删除目录、附件或工具结果；恢复后内容完整。
- [ ] 项目会话的删除不删除项目目录。
- [ ] 集成测试覆盖空目录清理、非空保留、附件与工具结果清理、归档不删；桌面 e2e 覆盖确认框中的保留路径。
