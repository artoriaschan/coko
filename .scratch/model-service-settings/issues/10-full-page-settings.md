# 10: 整页设置

**What to build:** 设置从浮层弹窗改为占满窗口的整页，外壳按 Pencil 源稿画面 01：左侧 240px 设置导航（48px 窗口控制安全区、“返回应用”、“搜索设置…”与分类菜单），右侧居中、最宽 800px 的详情区。打开设置时会话侧栏与聊天区隐藏但不卸载；“返回应用”、Escape 与再次按 ⌘, 回到应用；按菜单项名称搜索过滤导航。现有分区内容、分区注册表、离开守卫与“去设置”等入口的行为不变。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

规格：[模型服务 PRD](../spec.md) 2.1（2026-10-30 修订）；视觉：Pencil 源稿 `/Users/chenzheng/Desktop/UI/设置-模型服务.pen` 画面 01（外壳几何、颜色与位置；菜单项按规格 2.1 的规则）；界面约定 docs/tech-stack/ui.md 与 ui-design-system.md。

- [ ] ⌘,、侧栏设置按钮、Toast“去设置”打开整页设置并定位到指定分区；会话侧栏与聊天区隐藏，返回后 composer 草稿、消息滚动位置保持，进行中的 Run 继续且返回后可见其结果
- [ ] “返回应用”、Escape、再次按 ⌘, 回到应用；当前分区有未保存修改时先提示“放弃更改？”，取消则留在设置
- [ ] 设置内的弹窗、菜单或确认框打开时，Escape 只关闭它，不离开设置；聊天区“Run 进行中按 Escape 停止”在设置打开时不触发
- [ ] “搜索设置…”按菜单项名称过滤导航（当前语言与英文名称，不区分大小写），分类随之隐藏或显示，无匹配时显示空状态；清空后恢复；不搜索分区内设置项
- [ ] 菜单分组、未交付项隐藏、关于在底部、空分类不显示标题与现在一致；当前项有选中态（aria-current）
- [ ] 外壳几何与源稿一致：导航 240px、安全区 48px、返回行 H36、搜索框 H32/R12、菜单项 H32/R12、详情最宽 800px 居中；只用语义 token，明暗主题正确；窄窗口时导航与详情仍可用
- [ ] 焦点管理：打开设置时焦点进入设置导航或详情，返回应用时回到打开前的元素；Tab 顺序与可访问名称完整（设置区域有 landmark 与标题）
- [ ] 依赖弹窗角色的浏览器测试与 Electron E2E 改为新的定位方式并全部通过；当前行为文档（permissions、mcp 等）与源码注释中的“设置弹窗”同步改为“设置页”
