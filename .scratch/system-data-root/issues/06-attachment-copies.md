# 06: 附件副本

**What to build:** 用户粘贴或拖入的附件在发送时复制到 `~/.coko/data/attachments/<sessionId>/`，消息引用副本而不是原路径。原文件之后被移动或删除，历史消息仍能回看附件。图片保持 4.5 MB 上限，普通文件上限 32 MB，超限在输入区报错。

**Blocked by:** 01 主数据根切换到 ~/.coko

**Status:** ready-for-agent

- [ ] 发送带图片或普通文件的消息后，附件出现在 `data/attachments/<sessionId>/`，文件名带可读的原名与唯一前缀。
- [ ] 发送后移动或删除原文件，重新打开会话仍能查看附件内容。
- [ ] 图片超过 4.5 MB、普通文件超过 32 MB 时在输入区报错，消息不发送，不产生半截副本。
- [ ] 发送前图片草稿仍在 IndexedDB；发送成功后草稿引用被清理，未发送的草稿不写入 `data/attachments`。
- [ ] 复制失败时不发送消息，并保留可重试的草稿状态。
- [ ] 集成测试覆盖复制、原文件删除后的回看与超限报错；删除会话后的附件清理在 11 号票验证。
