# 项目技术规范

本目录是 [TECH_STACK](../TECH_STACK.md) 的分层正文，承接已有技术选型的详细约定。TECH_STACK 维护技术和精确版本，以下页面维护结构与接入要求；需求范围、功能提案和当前实现仍各有所属，边界按 [文档体系](../DOCUMENTATION_SYSTEM.md#需求已选型与实现的边界) 执行。

## 状态与维护

用户已确认的技术选择作为约束；候选、可选和待决项沿用各页标注，例如发布目的地尚未确定。各页引用的外部资料随正文保留，未逐项重新验证其版本事实。

这些页面描述应遵循的约定，不能据此声称功能已经实现、命令已经运行或安装包已经验收。实际实现证据进入当前架构、子系统/包说明和任务 evidence；实现偏差需显式处理。

版本变更维护 TECH_STACK；详细约定变更维护所属专项页。新方案提议先进入所属功能设计或决策材料，获得必要确认后更新生效约定；重要取舍的理由记录于 ADR。UI 规则的唯一正文在 [界面约定](ui.md) 及其具体档位页 [设计系统规格](ui-design-system.md)，测试规则在 [测试约定](testing.md)，AGENTS 只保留读取触发条件和链接。

TECH_STACK 每个领域只用一行链接到专项页，不保留重复的章节标题；活动引用直达所属专项正文。移动、替代或新增专项页时，同步本索引、受影响引用和文档体系目录图，按 [文档生命周期](../DOCUMENT_LIFECYCLE.md) 从入口读回核验。
