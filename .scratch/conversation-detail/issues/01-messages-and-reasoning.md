# 01: 消息正文与思考行复刻

**What to build:** 在真实 Session 消息区域中复刻用户消息、助手阶段回复与最终回答，以及思考的紧凑预览和手动展开。沿用 Coko 当前消息内容和操作，使消息改版可以在尚未引入过程分组时独立演示。

**Spec:** [对话详情与工作步骤复刻规格](../spec.md)

**Spec scenarios:** AC-01（消息与思考）、AC-09、AC-16（用户内容）、AC-23（单条开合）、AC-24、AC-25

**User stories:** 1、2、9、10、21、27—30

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Closed:** true

## Acceptance criteria

- [x] 同环境对照规格锁定的参考版本，消息列、用户消息、助手正文、Markdown、消息操作及思考行的字体、图标、颜色、材质和几何符合对应样式；顶部栏、输入框与侧栏几何保持原状。
- [x] 用户命令调用及展开全文、文件引用、图片附件、回退/分叉入口保留真实内容和既有回调；未获得操作资格时保持原有禁用规则，不以改版改变执行语义。
- [x] 空白推理不产生行；思考初始收起，流式期间也不自动展开；预览只使用参考规则允许的最近已完成首行，未完成单行不被当作完整预览。
- [x] 展开思考显示紧凑 Markdown；持续增量和结算不意外重挂载消息，不丢失用户选区、开合或正文内部阅读位置。
- [x] 通过真实 App 装配入口验证普通文本、Markdown、命令、引用、图片及思考边界，不以孤立组件截图代替实际组合。
- [x] 明暗主题、zh/en、390 CSS px 主内容宽度、长内容、键盘焦点和 reduced-motion 有对应验证；基线对照证据记录环境及未验证项。

## 范围与衔接

本票负责消息和思考自身的外观与交互。整轮/组级结构由 03 增加，过程折叠后的回退区间与历史行为由 11 联合验证；本票不能先移除这些已有能力。

规格锁定的参考提交、Coko 数据边界与非目标持续适用。不得修改数据库、协议和既有执行授权来凑齐展示数据，也不得用全局样式变化影响范围外页面。每票按实际变更更新所属当前行为文档；长期文档不反向链接本票。

## 验证与回执

- 采用规格的真实 App 装配入口及本票要求的现有 Sidecar/Electron 入口；纯函数测试只补充边界，不代替用户可见路径。
- 按当前实际改动选择相关测试，运行类型和文档检查；保留精确命令、实际数量、退出码、参考/当前对象版本、主题/语言/尺寸及可访问证据。只更新失效证据，不用盲目重试、固定 sleep 或放宽断言制造通过。
- 视觉与交互默认静默 agent-browser/CDP。获取资源后登记清理，结束时等待所属会话和进程实际退出，保留无关运行实例与用户数据。
- 完成后在 Comments 追加实施、验证、文档影响和实际交付状态；仍有必要验收缺口时如实记录，不提前关闭。不因前置票以 wontfix 关闭就自动认定阻塞解除。
