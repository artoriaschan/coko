# 07: 工具图片与预览

**What to build:** 用户能在工具和 MCP 结果中查看与参考一致的图片详情及画廊，打开大图并关闭返回原操作，同时保留 Coko 已有图片类型和宿主访问边界。

**Spec:** [对话详情与工作步骤复刻规格](../spec.md)

**Spec scenarios:** AC-10（工具图片）、AC-11（MCP 图片）、AC-12（图片结算）、AC-24

**User stories:** 11、14—16、25、27、29—31

**Blocked by:** [02：工具摘要行与通用详情](02-tool-rows-and-generic-details.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 图片缩略图、画廊、说明信息、展开详情和大图操作按参考对应视图复刻；缺少路径或尺寸记录时不虚构原始信息，实际可测量的尺寸明确取自真实图片。
- [ ] 已提交结果与实时结果依调用身份正确关联；工具结算不重复图片、不丢失原文本结果或使已打开的预览意外重置。
- [ ] 保留 Coko 对图片格式、来源与加载的现有约束，不渲染此前被禁止的内容；损坏或不可加载图片有可理解的失败表现。
- [ ] 大图操作、Escape、关闭按钮及焦点恢复正常；嵌套于工具/过程中的图片控件不误触外层开合。
- [ ] 多图、长说明、图片与文本混合结果在明暗主题、正常与 390 CSS px 主内容宽度下完整可用，无整页横向溢出。
- [ ] 通过真实 App 夹具输入真实位图结果，验证 MCP 图片、加载失败、实时结算及预览关闭；保留画廊与大图的视觉和交互证据。

## 范围与衔接

与 01 的用户消息附件分别拥有展示责任，复用已有图片能力时保持双方消费者稳定；只依赖 02，不新增图片服务协议。

规格锁定的参考提交、Coko 数据边界与非目标持续适用。不得修改数据库、协议和既有执行授权来凑齐展示数据，也不得用全局样式变化影响范围外页面。每票按实际变更更新所属当前行为文档；长期文档不反向链接本票。
