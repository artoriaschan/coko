# 10: 新建空白项目

**What to build:** 用户在侧栏新建空白项目，输入名称后 Coko 在 `<Documents>/Coko/projects/<名称>` 创建目录，注册 Project 与 Workspace，并打开一个以该项目为归属的新会话。名称去掉首尾空白、路径分隔符和前导点，空名称回退为“新项目”，重名追加 `-2`、`-3`。

**Blocked by:** 01 主数据根切换到 ~/.coko

**Status:** ready-for-agent

- [ ] 侧栏的“新建项目”流程提供“空白项目”入口，输入名称后目录出现在 `Documents/Coko/projects/` 下并自动打开新会话。
- [ ] 名称中的路径分隔符与前导点被去掉，首尾空白被裁剪；空名称创建名为“新项目”的目录。
- [ ] 同名目录已存在时追加 `-2`、`-3`，不覆盖已有目录。
- [ ] 创建成功后 Project 列表出现该项目，新会话的归属与主要 Workspace 正确；创建失败时不留下半成品项目或目录。
- [ ] 现有的“添加已有文件夹”创建项目流程不回归。
- [ ] 桌面 e2e 覆盖空白项目创建、重名、名称清洗与新会话发送。
