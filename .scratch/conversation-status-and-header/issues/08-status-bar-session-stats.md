# 08: 状态栏的会话统计

**What to build:** 状态栏在 Token 胶囊左侧增加会话统计胶囊，显示 `{轮} 轮 {步} 步 · {tps} tok/s`。点击后打开会话统计卡，显示模型用时、工具调用用时、首 token 平均耗时（TTFT）和输出速度（TPS）。

**规格场景:** [spec](../spec.md) 的 AC-01 中会话统计的部分、AC-02、AC-05 中两张卡互斥的部分；对应 STAT-04、STAT-05。

**设计依据:** 规格本身，没有单独的设计。

**文档影响:** workbench 当前行为说明的状态栏。

**Blocked by:** 07 — 输入框底部状态栏与 Token 用量（状态栏的行、卡片交互与共用的字段渲染）

**Status:** ready-for-agent

- [ ] 1 轮 = 本 Session 中至少发出过一次主循环模型请求的 Run：用户发送和 Goal Round 计入，单纯的 `/compact` 与交接摘要 Run 不计入。1 步 = 一次主循环模型请求，重试只计一次。
- [ ] 没有输出速度时省略 `· {tps} tok/s`；步数为 0 时不显示胶囊；缺少请求记录的旧 Session 不补造统计。胶囊图标为仪表，14px、stroke 1。
- [ ] 卡片的标题行：左侧为仪表图标加“会话统计”，右侧为 `{轮} 轮 {步} 步`。之后的行依次是：
  - 模型用时：主循环请求耗时之和。
  - 工具调用用时：从工具调用发出到拿到结果，包含审批等待，与 Trace 的工具耗时一致。
  - 首 token 平均（TTFT）。
  - 输出速度：输出 token 除以生成时间，生成时间 = 请求耗时减去 TTFT。

  值为 0 或未知的行不显示。
- [ ] 耗时小于 60 秒显示为 `45.2秒`，否则显示为 `2分42秒`。速度不小于 10 时取整，小于 10 时保留 1 位小数。
- [ ] 交互与 07 的 Token 卡一致；打开其中一张卡时，另一张关闭。
- [ ] 统计与格式化写成纯函数，用单元测试覆盖：多个 Run、失败后重试、`/compact`、交接摘要、缺少 TTFT、值为 0。真实 App 的 Browser Mode 测试覆盖胶囊与卡片的读数和交互。
- [ ] 同步修改 workbench 当前行为说明。实际执行的检查和文档影响记入 Comments。
