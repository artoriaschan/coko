# 10: `complete_plan` 与完成报告

**What to build:** 模型做完后提交一份对照计划的完成报告，Plan 变为已完成。用户在时间线计划卡与右栏 Plan 页看到报告：每一项做了什么、怎么验证的、哪些没做或偏离。完成不需要用户审批；完成后 Plan chip 消失，模型不再被提醒这份计划。见 [规格](../spec.md) 的“阶段二：执行中与完成”与设计稿。

**User stories:** 52、53、54、55、56、57、58、59、66（完成部分）、68

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] `complete_plan` 在规划中或执行中开始的 Run 注册；Subagent 的子 Session 的工具集中没有它
- [ ] 成功：依次提交已完成的 `plan` 条目（同 planId 与 revision，带报告）、计划阶段“无”与工具结果；结果文本按设计稿
- [ ] 批准之后的同一个 Run 中调用成功
- [ ] 不在执行中时调用、空报告、超过长度上限：返回错误结果，不提交条目，计划阶段不变
- [ ] 四种 Permission Mode 下都不询问；拒绝规则与询问规则照常生效
- [ ] 工具的说明与批准结果要求报告逐项对照计划写明做了什么、怎么验证、哪些没做或偏离；宿主不校验报告内容，不运行任何验证
- [ ] 报告入库与推送前替换登记的 Secret 明文；条目、推送与工具结果中没有明文
- [ ] 完成后的下一个 Run：执行中的 State Update 送达一次清空，之后不再发送；`<approved_plan>` 不再注入
- [ ] 回退到完成之前的消息：计划阶段回到执行中，Plan 的状态回到已批准
- [ ] 完成后用户继续对话是普通对话，没有活动的 Plan
- [ ] 桌面：时间线计划卡与右栏 Plan 页显示“已完成”与完成报告；Plan chip 消失
- [ ] Sidecar 集成测试与 renderer 浏览器测试覆盖以上各项
- [ ] 文档：Plan Mode、权限判定与审批中的权限类清单、桌面工作台；`pnpm run check:docs` 通过
